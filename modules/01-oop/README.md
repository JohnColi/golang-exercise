# Module 1：Go 的物件導向風格

對應 `golang學習項目.md` 的 Module 1。

## 檔案說明

| 檔案 | 用途 |
|------|------|
| `main.go` | 程式入口，串起兩個練習 |
| `embedding.go` | 練習 struct 內嵌與方法提升 |
| `interface.go` | 練習 interface 與鴨子型別 |

## 怎麼跑

```powershell
go run ./modules/01-oop
```

## 建議順序

1. 先完成 `embedding.go`，在 `main.go` 取消註解 `runEmbeddingDemo()`
2. 再完成 `interface.go`，取消註解 `runInterfaceDemo()`
3. 回到大綱，把對應的問題勾選起來
